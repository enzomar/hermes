Capabilities

Built for MCP & LLM developers

A unified interface for everything in your AI stack.

MCP Inspector

Browse connected MCP servers, view tool schemas, execute calls with form or JSON input, and inspect responses in real time.

Multi-Provider Chat

Converse with OpenAI, Anthropic, Google, Groq, OpenRouter, GitHub Models, DeepSeek, and local models through one interface.

Side-by-Side Benchmarks

Send the same prompt to two models simultaneously. Compare latency, token usage, and output quality in a split view.

Trace & Observability

Waterfall timeline of every LLM call and tool invocation. See span durations, token counts, and error traces per session.

Secure Keystore

API keys are encrypted locally and never leave your machine. Paste once, save, and the keystore resolves them automatically.

Debug API Console

Send raw HTTP requests to the Hermes backend. Browse all available endpoints, edit payloads, and inspect responses.

Integrations
